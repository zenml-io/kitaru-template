# PydanticAI returns agent moved

The maintained Python returns agent example now lives in the main Kitaru repository:

[`examples/python/pydantic_ai_ticket_resolver`](https://github.com/zenml-io/kitaru/tree/develop/examples/python/pydantic_ai_ticket_resolver)

Clone Kitaru and enter that directory before following its README:

```bash
git clone https://github.com/zenml-io/kitaru.git
cd kitaru/examples/python/pydantic_ai_ticket_resolver
```

The main repository also contains the [TypeScript ticket-resolver variant](https://github.com/zenml-io/kitaru/tree/main/examples/typescript/vercel_ai_ticket_resolver), Kitaru documentation, and the release-critical integration tests for both examples.

This repository is retained only to redirect existing links and should be archived after the migration PRs merge.
