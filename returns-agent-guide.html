Agent flow

1

Read the ticket

Work out whether it is about a return, a refund, delivery, or a missing order.

2

Look up the order

lookup_order gives the product, category, price, delivery state, and any earlier action.

Delivery issuecheck_shipping decides between a replacement and escalation.
Return or refundget_return_policy gives the rules for that category.
3

Choose an action

The agent picks a refund, replacement, or escalation.

4

Act, then reply

issue_refund, create_replacement, or escalate_to_human runs before the customer reply.
